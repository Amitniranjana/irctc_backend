# Frontend Documentation

This folder contains the Next.js frontend for the IRCTC backend project.

## Purpose

The frontend is currently a lightweight starter application that can be extended to connect with the backend authentication APIs.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

The development server starts on:

- `http://localhost:3000`

## Useful commands

```bash
npm run build
npm run start
npm run lint
```

## Project structure

```text
src/
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
└── ...
```

## Notes

- The current UI is a starter page generated by Next.js.
- The backend API is expected to be available on `http://localhost:3000` from the Express service.
- The frontend can be enhanced to call `/api/auth/signup` and `/api/auth/verify-otp` once the actual UI flow is implemented.
